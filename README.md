# MAGRA

**Pierde grasa. Conserva lo que importa.**

App de pérdida de grasa con IA para Android, iPhone, Windows, macOS y web
(Flutter). Cuenta calorías con una foto, arma menús con marcas reales,
calcula lo que quemas al entrenar y ajusta tu meta cada semana según tu
progreso real.
